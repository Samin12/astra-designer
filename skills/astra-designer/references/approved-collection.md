# Production standard

Use with [hero-depth.md](hero-depth.md). These are design principles, not claims about previous clients or user approvals.

## 1. Research the actual brand
Use supplied identity, owned assets and verified product facts. Record source URLs and distinguish proposals from established brand rules. Never invent customers, awards, testimonials or metrics.

## 2. Build independent depth
Document background, subject, foreground and atmosphere as separate assets. Specify each plane's opening, midpoint and exit, shared contact anchors, occlusion and mobile crop. Keep text in semantic HTML.

## 3. Choose the appropriate medium
Photographic compositing suits real products and people. Real 3D suits geometry, rotating objects and useful lighting controls. Native sticky layers often provide enough depth without video. Use Higgsfield for missing media; see [assets.md](assets.md).

## 4. Give the page its own structure
Choose grammar, navigation, information order and a useful ending. Follow [uniqueness.md](uniqueness.md). A color swap is not a new composition.

## 5. Make controls useful
Selectors must change meaningful information. Forms need real destinations and honest success/error states. Do not label a local illustration as a live integration. Preserve selections when they matter to the visitor's next action.

## 6. Art-direct phones
Recompose type and imagery for portrait screens. Provide matching posters, reduced-motion and no-JavaScript paths. Keep essential information visible without animation.

## 7. Require visual and functional evidence before delivery
Run [verify.md](verify.md), inspect desktop, mobile and reduced-motion contact sheets, exercise keyboard navigation and useful controls. Disable native pointer capture/lock in headless contexts. Recheck the deployed URL and its assets after publishing; a local build is not deployment proof.
